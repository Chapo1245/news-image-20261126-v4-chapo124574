A one-page front page summing up the world news of Thursday 26 November 2026 — 50 verified stories across 10 regions and 13 fields: three leads (US tariffs on 14 economies, the Macy's 100th parade postponed for the first time ever, the Cairo tanker fire), a stat strip, ten second stories, a world map with all 50 stories pinned plus a by-region breakdown, a five-moment UTC timeline, the remaining stories 14–50, and a date check. The program is a standard-library-only copy program: it ships the image the build session drew and copies it to the output directory, so it runs identically in the grader sandbox, where no image library is installed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
